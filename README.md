# نظام كشك متعدد الخدمات | Multi-Services POS

نظام نقاط بيع وإدارة متكامل وسريع للمحلات والأكشاك التجارية المتعددة الخدمات (تبغ، حلويات، مواد غذائية، ألعاب، خدمات رقمية، بطاقات شحن، ومكسرات بالميزان).

---

## 🏗️ معمارية وهيكل المشروع (Project Structure)

المشروع مبني بلغة **TypeScript** مع **React 18** و **Vite** و **Tailwind CSS**.

```
/
├── index.html                  # مدخل الصفحة الرئيسي والوسوم الوصفية
├── package.json                # الحزم والتبعيات وأوامر البناء
├── metadata.json               # إعدادات وصلاحيات التطبيق
├── src/
│   ├── main.tsx                # نقطة تشغيل تطبيق React
│   ├── App.tsx                 # المتحكم الرئيسي بالتنقل والجلسات
│   ├── types.ts                # جميع المخططات والأنواع (TypeScript Schemas)
│   ├── index.css               # التنسيقات العامة و Tailwind CSS
│   ├── data/
│   │   └── seedData.ts         # البيانات الأولية والتصنيفات الافتراضية
│   ├── services/
│   │   └── storage.ts          # محرك قواعد البيانات وإدارة العزل وتخزين البيانات
│   ├── components/
│   │   ├── Auth/               # بوابات الدخول، تسجيل الحسابات، وصلاحيات الأدمن والكاشير
│   │   ├── POS/                # شاشة نقطة البيع الرئيسية، السلة، الباركود، والوزن
│   │   ├── Inventory/          # إدارة المخزون، المنتجات، التصنيفات، وسلة المهملات
│   │   ├── Sales/              # سجل الفواتير، استرجاع المبيعات، والطباعة
│   │   ├── Customers/          # دليل العملاء، كشف الحساب، وإدارة الديون والتسديد
│   │   ├── Reports/            # لوحة الإحصائيات، الأرباح، والتقارير المالية
│   │   ├── Settings/           # إعدادات المتجر، النسخ الاحتياطي، وإدارة المستخدمين
│   │   └── Common/             # المكونات المشتركة، الأزرار، والنوافذ المنبثقة
```

## ⚡ المميزات والواجهات المنفذة بالفعل

1. **شاشة نقطة البيع (POS View)**:
   - دعم قارئ الباركود، البيع السريع باللمس، حساب الوزن التلقائي للسلع الموزونة.
   - تعليق واسترجاع الطلبات (Hold / Resume).
   - دعم الدفع المتعدد (نقدي، بطاقة، آجل / كريدي).

2. **المصادقة والصلاحيات (Authentication & RBAC)**:
   - نظام صلاحيات مزدوج (مدير عام / كاشير).
   - حماية الصفحات الحساسة برمز PIN.
   - عزل تام لبيانات كل حساب وكاشير.

3. **إدارة المخزون (Inventory & Stock)**:
   - إضافة، تعديل، حذف، واسترجاع من سلة المحذوفات.
   - تنبيهات انخفاض ونفاد المخزون.
   - تصدير واستيراد بصيغة Excel / CSV / JSON.

4. **نظام الفواتير والطباعة (Invoices & Printing)**:
   - طباعة حرارية احترافية (80mm / 58mm).
   - خيار الحفظ كـ PDF ومشاركة الإيصال.
   - أرقام فواتير تسلسلية وتاريخ دقيق.

5. **إدارة الديون والعملاء (Customers & Debt Management)**:
   - كشف حساب لكل عميل وسجل تسديد الأقساط.

6. **التقارير المالية (Financial Reports & Analytics)**:
   - تتبع الإيرادات، صافي الأرباح، المصاريف، وأكثر المنتجات مبيعاً.

- **فحص الكود**: `npm run lint`
